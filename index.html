Aviator Update Guide

  1. Preserve the supplied source at DOB98_User_Panel/legacy/aviator-standalone-2.original.html.
  2. Legacy styles are in its first <style> block. The engine is the inline script around line 334; the overlay and round UI begin around line 490.
  3. No GAME_HTML variable was found in the supplied file. Search the original source for RXEngine, roundSchedule, and rx_wallet to find its major sections.
  4. New DOB98 game presentation: index.html section #aviator; styling: css/app.css; demo controls: js/app.js.
  5. Do not alter authentication, API wallet endpoints, transaction ledger, or idempotency checks when deploying a new game version. Real-money game outcomes must come from a licensed provider/server-side integration.

Post-update checklist

  • Check desktop, tablet and mobile layouts.
  • Check source paths and browser console errors.
  • Verify login, email verification, and user isolation.
  • Test server-side bet/cashout with a test provider in a staging environment; the included game is demo-only.
  • Test deposit pending → approve/reject and withdrawal reserve → approve/reject flows.
  • Verify bKash setting propagates to user panel; confirm Nagad stays unavailable.
  • Confirm repeated admin requests cannot process the same transaction twice.
